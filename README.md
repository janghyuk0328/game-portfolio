## 미디어 실행 안내
YouTube HTML iframe 퍼가기는 웹사이트(HTTPS)에서 동작합니다. HTML을 `file://`로 직접 열면 Referer 정보 문제로 오류 153이 발생할 수 있습니다. YouTube 소유자가 삽입 제한을 설정했거나 브라우저/네트워크가 재생을 차단한 경우에는 플로팅 플레이어에 있는 `YouTube ↗` 버튼으로 원본 영상을 확인할 수 있습니다. GitHub Pages에서 실제 재생 여부는 배포 후 검증해야 합니다.
