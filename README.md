# 윤장혁 | 게임 기획자 포트폴리오 (v4.11)

GitHub Pages에서 사용하는 정적 웹사이트입니다. 별도 빌드 없이 `index.html`, `style.css`, `script.js`, `content.js`, `assets/`를 저장소 최상위에 둡니다.

## 이번 수정 내용

**AI 활용 섹션 마지막에 고전 던전 크롤러 개인 프로토타입 사례를 추가했습니다.** 웹사이트에만 추가한 내용이며, 포트폴리오 개요·이력서·기획서 PDF는 변경하지 않았습니다.

### 소개 문구

> Battle Arena 제작과 병행해 새벽 시간을 활용하여 개인 프로토타입을 개발하고 있습니다.
>
> ChatGPT·Codex로 **역할별 에이전트 팀을 구성해 게임을 만드는 방식**을 시도하고 있습니다.

2026년 · 3학년 · 개인 프로젝트로 표기하고, **개발 중** 상태를 표시했습니다.

### 이미지와 영상

- 새로 제공한 `image(8).png`를 대표 이미지로 사용합니다. 원본 이미지 확대 버튼도 제공합니다.
- 제공한 플레이 영상 전체(약 4분 58초)를 **해당 영역에서 바로 재생**할 수 있습니다.
- 자동 재생하지 않으며, 재생 버튼을 누르기 전에는 대표 이미지를 표시합니다.
- 영상은 원본의 808×458 해상도, 30fps, 전체 길이와 오디오를 유지해 웹용 MP4로 최적화했습니다.
- 데스크톱에서는 왼쪽 설명·오른쪽 영상, 좁은 화면에서는 설명 다음에 영상을 표시합니다.

## 이전 수정분 포함

2026 G-STAR 전시 제목과 인라인 현장 영상, 전시 사진 4장, 레벨 동선 로그 검증 자료, 최신 버프 UI 원본 이미지 2장을 포함합니다. 최신 개요·이력서·기존 AI 활용 사례도 함께 들어 있습니다.

## 업데이트 방법

### 기존 v4.3~v4.10 사이트가 있는 경우

**`포트폴리오_v4_11_업데이트파일.zip`**을 사용합니다. 이전 이력서·INDIECRAFT·최신 개요·AI 활용·G-STAR 반영분을 포함한 **21개 파일의 누적 업데이트**입니다.

1. ZIP을 풉니다.
2. 압축 안의 `index.html`, `style.css`, `script.js`, `content.js`, `README.md`를 기존 `game-portfolio` 저장소의 같은 위치에 덮어씁니다.
3. `assets/`를 기존 `assets/`에 **합쳐서** 같은 이름의 파일을 덮어씁니다. 기존의 다른 이미지·문서도 계속 필요합니다.
4. 새 플레이 영상 **`assets/videos/ai-dungeon-prototype.mp4`**와 기존 전시 영상을 포함한 `assets/videos/`도 반드시 함께 복사합니다.
5. GitHub Desktop에서 변경 파일을 확인하고 `Commit to main` 후 `Push origin`을 실행합니다.
6. GitHub Pages 배포가 완료되면 공개 사이트를 확인합니다. 이전 화면이 보이면 강력 새로고침을 사용합니다.

### 전체 파일이 필요한 경우

**`윤장혁_게임기획_포트폴리오_v4_11_AI개인프로젝트.zip`**을 사용합니다. 압축 안의 `index.html`이 저장소 최상위에 오도록 복사합니다.

기존 사이트 주소: https://janghyuk0328.github.io/game-portfolio/

압축파일 준비와 GitHub 게시 작업은 별개입니다. 저장소에 반영하고 Push해야 공개 사이트가 갱신됩니다.

## 유지되는 구성

- HOME → 경험과 성장 → 프로젝트 → 개인 기획서 → 엔진과 도구 → AI 활용 → 연락처 순서입니다.
- 프로젝트의 연도와 학년, 최신순 경험, 프로젝트별 마지막 회고를 유지합니다.
- SPLIT 대표 카드는 세로형이며, 클릭 후 재생창은 다른 게임과 같은 **16:9 플로팅 플레이어**입니다.
- 기존 게임 영상을 재생하면서 페이지를 스크롤할 수 있습니다. Trello 자동화 영상은 중앙 모달로 열립니다.
- Rolling LEO와 SPLIT의 기존 전시 사진 구성과 영상 주소, 개인 기획서 2종을 유지합니다.
- 상단 및 본문의 이력서 다운로드와 연락처를 유지합니다.
- 개요는 최신 29페이지 원본, 이력서는 최신 2페이지 원본입니다.

## 확인한 사항

- 새 대표 이미지가 제공한 원본과 바이트 단위로 일치합니다.
- 새 영상은 원본과 같은 해상도·프레임률·전체 길이를 유지합니다.
- 데스크톱 및 모바일 폭에서 새 영역 배치·원본 비율·가로 넘침 여부를 확인했습니다.
- 해당 위치에서의 영상 재생과 대표 이미지 확대 연결을 확인했습니다.
- 기존 모든 PDF와 JavaScript 파일은 변경하지 않았습니다.

YouTube 삽입은 GitHub Pages 등 HTTP(S) 환경에서 확인합니다. 파일을 직접 여는 `file://` 환경에서는 영상의 Referer 관련 오류가 생길 수 있습니다.
