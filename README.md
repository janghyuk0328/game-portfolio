## 이전 수정분 포함

AI 활용의 고전 던전 크롤러 개인 프로토타입, 대표 이미지와 전체 플레이 영상(약 4분 58초)을 유지합니다.

> Battle Arena 제작과 병행해 새벽 시간을 활용하여 개인 프로토타입을 개발하고 있습니다.
>
> ChatGPT·Codex로 **역할별 에이전트 팀을 구성해 게임을 만드는 방식**을 시도하고 있습니다.

2026년 · 3학년 · 개인 프로젝트이며 개발 중 상태로 표시합니다. 이 사례는 웹사이트에만 들어 있습니다.

2026 G-STAR 전시 제목과 인라인 현장 영상, 전시 사진 4장, 레벨 동선 로그 검증 자료, 최신 버프 UI 원본 이미지 2장, 최신 개요·이력서·기존 AI 활용 사례도 포함합니다.

## 업데이트 방법

### 기존 사이트에 이번 변경 적용

**`포트폴리오_v4_12_업데이트파일.zip`**을 사용합니다. v4.3 이후 수정분을 포함한 **22개 파일의 누적 업데이트**입니다.

1. ZIP을 풉니다.
2. 최상위의 `index.html`, `content.js`, `style.css`, `script.js`, `README.md`, `YOUTUBE_퍼가기_HTML_참고.txt`를 저장소의 같은 위치에 덮어씁니다.
3. `assets/`를 기존 `assets/`에 합쳐서 같은 이름의 파일을 덮어씁니다. 기존의 다른 이미지·문서도 계속 필요합니다.
4. 개인 프로젝트와 전시 영상이 들어 있는 `assets/videos/`도 함께 복사합니다.
5. GitHub Desktop에서 변경 파일을 확인하고 `Commit to main` 후 `Push origin`을 실행합니다.
6. GitHub Pages 배포가 완료되면 공개 사이트를 확인합니다. 이전 화면이 보이면 강력 새로고침을 사용합니다.

**이미 v4.11을 모두 적용했다면:** 실제 사이트 동작에 필요한 교체 파일은 `index.html`, `content.js` 두 개입니다. `README.md`와 `YOUTUBE_퍼가기_HTML_참고.txt`도 함께 바꾸면 안내 자료까지 최신 상태가 됩니다. 이번 수정에는 새 이미지·영상·PDF 파일이 없습니다.

### 전체 파일이 필요한 경우

**`윤장혁_게임기획_포트폴리오_v4_12_배틀아레나영상갱신.zip`**을 사용합니다. 압축 안의 `index.html`이 저장소 최상위에 오도록 복사합니다.

기존 사이트 주소: https://janghyuk0328.github.io/game-portfolio/

압축파일 준비와 GitHub 게시 작업은 별개입니다. 저장소에 반영하고 Push해야 공개 사이트가 갱신됩니다.

## 유지되는 구성

- HOME → 경험과 성장 → 프로젝트 → 개인 기획서 → 엔진과 도구 → AI 활용 → 연락처 순서입니다.
- 프로젝트의 연도와 학년, 최신순 경험, 프로젝트별 마지막 회고를 유지합니다.

- 2026 G-STAR 현장 영상과 개인 던전 프로토타입 영상은 각 카드 안에서 재생됩니다.
